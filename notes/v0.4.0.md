Your own words for things, the system's switches at hand, and file search that finds more, faster, without slowing you down.

- **Aliases.** Give an app, command, snippet or quicklink your own word: Ctrl K → Set Alias. Type it and that comes first. Settings → Aliases lists them.
- **System commands.** Empty Recycle Bin (it asks first), Toggle Dark Mode, Mute and the volume, Show Desktop on Windows, and Open Downloads.
- **File search finds more.** No limit on how many files it keeps: big folders are looked through slowly, at low priority, instead. Names match loosely ("rprt" finds report.pdf), files you opened lately come first, and Show All Files lists every match. It searches on its own thread, so typing never waits for it.
- **More about a file.** The details pane shows a file's size and when it changed, a picture for images, and the first lines of text and code files. Open in Terminal opens one in a file's folder.
- **Recent Files** before you type: what you last opened from Tendril. The Files tab can turn it off.
- **Search in Settings.** A box above the tabs finds any setting.
- **Quicker to hand.** ↑ brings back your last searches, Tab opens the actions (or fills in a path), Ctrl Backspace clears what's typed, right-click opens a row's actions, and the bar along the bottom shows what Ctrl Enter does.
- **Smoother opening.** Tendril no longer redoes work each time it opens, and the list no longer jumps a second later.

The first release of Tendril, a keyboard launcher in the style of Raycast. Native (Rust and Slint, no web view), about 19 MB while closed, and nothing running between uses.

- **Apps, sums and commands.** Find any installed app, do arithmetic as you type, lock, sleep or shut down, and search the web.
- **Quicklinks and files.** Your own links with keywords (`gh devatloam/tendril`), and any folder listed as you type its path.
- **Clipboard history.** What you've copied, searchable, pasted back into the window you were in. Kept on your computer only.
- **Switch windows.** Every open window, most recent first (Linux under X11, and Windows).
- **Yours to shape.** Themes from Blight, blur where your system has it, Flat or Modern style, compact or with details, all from the Appearance view or a first-run walkthrough.
- **Keeps itself up to date.** Checks GitHub every six hours and installs new versions for the next start, or follows nightly previews if you'd like them first.

Built and used on Linux under X11. The Windows and macOS builds compile and pass their checks but haven't been run on those systems yet, so expect rough edges there. macOS builds aren't signed: open Tendril.app the first time with right-click → Open.

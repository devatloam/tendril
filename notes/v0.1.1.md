Fixes from the first run on Windows.

- **Typing keeps up.** App icons load in the background instead of holding up each keystroke, which on Windows could stall the list for seconds.
- **Sharp icons.** Each icon is scaled to the exact size it's shown at, for your display's scaling, instead of being squeezed into it.
- **Clicking away closes it on Windows,** and Tendril makes sure it's the window in front when it opens.
- **Starting Tendril again brings up the one that's running** on Windows, as it does on Linux and macOS.
- **Taken shortcuts are explained.** When another app already holds your keys (Alt+Space is Raycast's and PowerToys Run's), Tendril tells you and the walkthrough asks for others. Alt combinations can now be recorded on Windows.
- **The GPU asks first.** Turning on the Modern style, or blur on Windows and macOS, explains what drawing with the GPU costs before it restarts Tendril.
- **Nightlies come once a night** when there's something new, rather than after every change.
